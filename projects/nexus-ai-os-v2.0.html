Overview & Multi-Agent Architecture

Nexus AI OS operates as a local operating system designed specifically for AI-driven automation. By translating user requests into structured graph execution flows (DAGs), it enables complex, multi-step actions (such as filesystem tasks, browser operations, and coding) to run autonomously.

The system features a decoupled dual-mode configuration: running in SQLite/JSON mode for zero-container offline testing, or PostgreSQL/Redis/MongoDB/Qdrant mode for scalable enterprise production deployments.

Build Details

The workspace is engineered as a robust control plane dividing planning, safety supervisor audits, and tool interfaces.

01

Goal Planner & Execution

Parses high-level natural language command strings into a modular execution plan represented as a JSON DAG. Handles asynchronous queues dynamically.

02

Supervised Safety Gate

Interposes a Supervisor agent that audits task inputs and triggers human-in-the-loop permission prompts for shell commands, filesystem deletes, or calendar updates.

03

MCP Client Integration

Exposes standard tools alongside Model Context Protocol (MCP) clients to dynamically coordinate stdio JSON-RPC connections for external system actions.

04

Decoupled Memory & RAG

Coordinates Redis caching, MongoDB audit logging, SQLite/PostgreSQL relational data, and Qdrant semantic vector indexes to provide robust grounding context.

Challenges Solved

Solved model hallucination and loop locks by implementing pre-run cycle verification and Supervisor safety timeout rules.

Addressed tool coordination overhead through the implementation of a custom stdio JSON-RPC MCP client registry, and managed state persistence and latency via a tiered memory architecture (Redis + Mongo + Postgres).

Future Scope

Expanding the system to support advanced human-in-the-loop workflow editing directly in the graph UI, and introducing multi-user collaboration rooms for shared agent control.

Additionally, plans include expanding the MCP connector library to include popular enterprise software integrations and training fine-tuned local models for task planning and execution.
