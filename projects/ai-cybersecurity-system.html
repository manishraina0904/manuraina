Overview & Problem Statement

This project presents an intelligent cybersecurity solution designed to combat modern phishing attacks and emerging threats introduced by Generative AI. It combines machine learning, natural language processing, and computer vision to detect malicious emails and provide a scalable framework for deepfake detection.

The rapid growth of Generative AI has enabled cybercriminals to create highly convincing phishing emails and synthetic media. Traditional security systems struggle to identify these sophisticated attacks. This system provides an AI-driven approach for detecting phishing messages while establishing a modular architecture for deepfake detection.

Project links and notes

Build Details

The security platform leverages text preprocessing, machine learning classifiers, and CV feature extractors.

01

NLP Classification

Processes text content using tokenization, cleaning, and TF-IDF feature extraction. Evaluates Logistic Regression and Naive Bayes models dynamically.

02

Computer Vision Indicators

Measures image properties to identify synthetic media. Implements Laplacian variance filters for blur, edge analyzers, and noise estimators.

03

Hybrid Rules Engine

Augments model inferences with deterministic logical checks to intercept phishing variants, enhancing model recall in actual deployments.

04

Validation Suite

Maintains over 80 real-world validation scenarios. Analyzes precision/recall metrics, tracking a dataset accuracy of ~96% and real-world accuracy of ~88%.
